# Умный Шопинг — MVP (запасной вариант)

Агрегатор цен на игры и игровые товары: ищет предложения у продавцов **Plati.market** и в **официальных магазинах**
(Steam, GOG, Humble, Fanatical, GreenManGaming и др. — через открытый API CheapShark), склеивает их с игрой из **Steam**,
показывает надёжность продавца, регион активации, историю цены и даёт персональную рекомендацию.
Есть помощник на **своей обученной нейросети ShopNLU** (без внешнего ИИ, см. [docs/МОДЕЛЬ.md](docs/МОДЕЛЬ.md)), избранное с уведомлениями об изменении цены, сравнение и вход.

Заявка ОПД 1364 «Умный Шопинг», сдача 30.11.2026.

## Запуск

Нужны Python 3.11+ и Node.js 20+ (Node — только чтобы собрать фронтенд один раз).

```
run.bat
```

Скрипт ставит зависимости, собирает фронтенд, при первом запуске в фоне загружает цены 20 популярных игр и открывает
http://127.0.0.1:8790/ . Документация API — http://127.0.0.1:8790/docs .

Вручную:

```
python -m pip install -r requirements.txt
cd frontend && npm install && npm run build && cd ..
python -m app.loader --top 30          # загрузить цены в базу (≈5 мин)
python -m uvicorn app.main:app --port 8790
```

Разработка фронтенда с горячей перезагрузкой: `cd frontend && npm run dev` → http://localhost:5173 (запросы `/api` идут на 8790).

Помощник по умолчанию работает на своей модели ShopNLU (веса уже лежат в `app/nlu/shopnlu.npz`, нужен только numpy).
Переобучить: `pip install -r requirements-train.txt` и `python -m app.nlu.train` (~2,5 мин). Внешний Claude можно включить
по желанию: `ASSISTANT_ENGINE=claude` и `ANTHROPIC_API_KEY` в `.env`.

Тесты (офлайн, внешние API подменены): `python -m unittest discover -s tests -v` — 39 тестов.

## Что где

| Путь | Что |
|---|---|
| `app/sources.py` | Источники: Steam (справочник), Plati.market, CheapShark + курс ЦБ; определение типа, платформы, региона, DLC, надёжности |
| `app/service.py` | Поиск: склейка с игрой, фильтры, кэш 15 мин, запись в базу, ответ из базы, если Plati не отвечает |
| `app/db.py` | База SQLite `data/shop.db`: product, store, offer, price_history, app_user, user_session, user_data |
| `db/schema.sql` | Та же схема для PostgreSQL |
| `app/loader.py` | Загрузчик цен: топ Steam + список популярных платных игр, разово или `--every-hours 24` |
| `app/auth.py` | Регистрация/вход: PBKDF2-SHA256, токен сессии хранится хэшем, cookie HttpOnly, блокировка после 5 ошибок |
| `app/nlu/` | Своя модель ShopNLU: признаки, словари, генератор датасета, обучение (PyTorch), инференс (numpy), тестовые наборы |
| `app/smart.py` | Ответы помощника по разбору модели: покупка, подбор из каталога, отзывы, сравнение цен, справка |
| `app/assistant.py` | Выбор режима (model / rules / claude), поиск с ослаблением условий, режим правил |
| `app/main.py` | API (FastAPI) + раздача собранного фронтенда |
| `frontend/` | React + TypeScript + Vite: главная, каталог, поиск, карточка игры, помощник, сравнение, избранное, вход, профиль |

## API

| Метод | Что делает |
|---|---|
| `GET /api/search?q=&kind=&platform=&store=&max_price=&trusted_only=&sort=&limit=` | Поиск предложений с фильтрами и фасетами |
| `GET /api/games/{appid}` | Карточка игры: данные Steam, все предложения, лучшее по каждому типу |
| `GET /api/offers/{id}/history` | История цены (для графика) |
| `POST /api/offers/current` | Текущие цены по списку id (для уведомлений в избранном) |
| `GET /api/catalog`, `GET /api/deals`, `GET /api/stores` | Каталог из базы, «Выгодно сегодня», подключённые площадки |
| `POST /api/assistant` | Вопрос → ответ, до 3 предложений и разбор запроса моделью (`nlu`) |
| `POST /api/nlu` | Только разбор запроса моделью: намерение, игра, тип, платформа, бюджет, жанр |
| `POST /api/auth/register`, `/login`, `/logout`; `GET /api/me`; `PUT /api/me/profile`, `/api/me/favorites` | Пользователь, профиль, избранное |

Старые методы (`search`, `games`, `history`, `assistant`) не менялись — только добавлены поля
`region`, `old_price`, `note` и тип `магазин`.

## Соответствие критериям приёмки брифа

Полная сверка с брифом, функциями Ф1–Ф32 из отчёта 2 и требованиями куратора — [docs/СООТВЕТСТВИЕ_ТЗ.md](docs/СООТВЕТСТВИЕ_ТЗ.md). Исходные документы ТЗ — `docs/ТЗ/`.

| Критерий | Как выполнено |
|---|---|
| ≥ 3 релевантных площадки | Plati.market + официальные магазины через CheapShark (Steam, GOG, Humble, Fanatical, GMG и др. — обычно 3–8 на игру); список — `GET /api/stores` |
| Агрегатор: цена, наличие, рейтинг продавца | Таблица предложений: цена в ₽, тип, платформа, продавец, отзывы +/−, возвраты, продано, шкала надёжности |
| Расчёт доставки с учётом региона | Регион активации из описания (RU / СНГ / Global / KZ / TR / EU / «не для РФ») сравнивается с регионом из профиля; способ и срок получения для каждого типа товара |
| Персонализированная рекомендация по профилю | Блок «Рекомендуем вам» в поиске и карточке игры: бюджет, платформа, типы, регион + объяснение выбора; помощник на своей модели тоже учитывает профиль и подбирает игры по жанру и бюджету |
| Дашборд сравнения: таблица, сортировка, фильтры | Сортировка по клику на колонку; фильтры по типу, платформе, магазину, цене, надёжности, региону; страница «Сравнение» до 4 предложений |
| Избранное + уведомления об изменении цены | ♥ сохраняет цену в момент добавления; цены обновляет загрузчик; изменения — значок в меню, плашка и подсветка в «Избранном» |
| Обработка запроса ≤ 10 с | Живой поиск обычно 2–8 с (время показывается под результатами), повторный — из кэша мгновенно; каталог — из базы |
| Безопасная аутентификация | PBKDF2-SHA256 200 000 итераций с солью, токен 256 бит хранится хэшем, HttpOnly + SameSite cookie, блокировка перебора, валидация |
| Понятный интерфейс (рекомендация за 3 мин) | Главная → строка запроса или подсказка → помощник (своя модель, ответ за доли секунды + поиск) отвечает с карточками и показывает, как понял запрос; светлая/тёмная тема, мобильная версия |

## Ограничения

- Цены официальных магазинов — в долларах (США), пересчитаны по курсу ЦБ; оплата там зарубежной картой.
- Регион определяется по названию предложения — если продавец его не указал, показываем «регион не указан».
- GGsel не подключён: партнёрский токен так и не получили; при появлении — добавить метод в `sources.py` по образцу Plati.
- Уведомления — внутри сервиса (без почты и пушей).
