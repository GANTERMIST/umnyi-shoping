## Ошибки на ручном тесте

- «сколько стоит Clair Obscur Expedition 33»: game = expedition 33 (надо clair obscur expedition 33)
- «что скажешь про Clair Obscur»: game = clair (надо clair obscur)

## Ошибки на слепом тесте

- «Dispatch стоит брать?»: intent = buy (надо review)
- «сравни цены на подземелье хаоса»: game = подземелье (надо подземелье хаоса)
- «реши пример 15 умножить на 4»: intent = buy (надо other); game = пример (надо None)
