## 1. Критерии приёмки из брифа

| Критерий | Статус | Как выполнено / что не так |
|---|---|---|
| Поиск находит ≥ 3 релевантных площадок | ✅ | Plati.market + магазин SteamBuy (гифты/ключи в ₽, сопоставление по Steam appid) + официальные магазины через CheapShark: Steam, GOG, Humble, Fanatical, GreenManGaming, GamersGate, IndieGala, Epic и др. (в базе 13 площадок); `GET /api/stores` |
| Агрегатор: цена, наличие, рейтинг продавца | ✅ | Таблица предложений: цена (у продавцов в ₽, у официальных магазинов в $ без пересчёта), тип, платформа, продавец, отзывы +/−, продано, возвраты, надёжность. «Наличие» — предложение показывается, только если товар выставлен (`visibleOnly`) |
| Расчёт доставки с учётом региона | 🟡 | Товары цифровые, денежной доставки нет. Вместо неё — способ и срок получения по типу товара и проверка региона активации (RU / СНГ / Global / «не для РФ»…) против региона из профиля |
| Персонализированная рекомендация по профилю | ✅ | Блок «Рекомендуем вам» (поиск, карточка игры): бюджет, платформа, типы, регион + объяснение по пунктам |
| Рекомендации учитывают историю предпочтений | ✅ | Если в профиле не указано — платформа и тип берутся из избранного («как в вашем избранном»); история просмотров «Вы смотрели»; похожие игры |
| Дашборд сравнения: таблица, сортировка, фильтры | ✅ | Сортировка по клику на колонку; фильтры: тип, платформа, магазин, цена, надёжность, регион; страница «Сравнение» до 4 предложений с выводом |
| Избранное + уведомления об изменении цены | ✅ | ♥ запоминает цену, целевая цена, значок в меню и плашки «цена изменилась» / «целевая цена достигнута». Письма на email нет (см. п. 3) |
| Условия возврата и гарантии | ✅ | Строка 🛡 у каждого предложения и в сравнении: гарантия Plati (спор в заказе) / правила возврата магазина |
| Отзывы и рейтинги | ✅ | Отзывы о продавце (Plati), % положительных отзывов Steam и Metacritic об игре |
| Веб-платформа и мобильное приложение | 🟡 | Адаптивный сайт + PWA: устанавливается на телефон как приложение (manifest + service worker). Отдельного нативного приложения нет |
| Время обработки запроса ≤ 10 с | ✅ | Живой поиск 2–8 с (время показывается под выдачей), повтор — из кэша мгновенно, каталог и помощник по каталогу — доли секунды |
| Разные типы товаров (электроника, одежда…) | 🟡 | Командой сознательно сужено до игровых товаров (решение от 01.11, `docs/ИСТОЧНИКИ_ДАННЫХ.md`): игры всех жанров, ключи, гифты, аккаунты, пополнения валюты. Электроники и одежды нет — это нужно объяснить на защите |
| Данные защищены, аутентификация безопасна | ✅ | PBKDF2-SHA256 200 000 итераций с солью, токен 256 бит хранится хэшем, cookie HttpOnly + SameSite, блокировка после 5 неверных паролей, валидация |

Итого: из 26 функций MVP — 20 ✅, 6 🟡, 0 ❌; из 6 отложенных одна (Ф4) сделана.

Отличия от архитектуры отчёта 2: React + Vite вместо Next.js, SQLite (схема для PostgreSQL — `db/schema.sql`) вместо PostgreSQL, свой загрузчик вместо Celery/Redis, своя модель ShopNLU вместо YandexGPT/GigaChat (модель не выдумывает товары — как и требовал отчёт: она только разбирает запрос, товары берутся из поиска).

## Дизайн

Интерфейс приведён к утверждённым макетам команды (отчёт 3, таблица 2): чёрный монохром #000 / #111, линии #222 без теней, текст #fff / #888, единственный акцент #007AFF для активного и метки «лучше», Inter + JetBrains Mono для цен, острые углы, белые основные кнопки. Раскладки страниц — как на макетах: шапка-сетка, главная с запросом помощнику, выдача с фильтрами слева и панелью «К сравнению» внизу, карточка игры «фото слева — цена и покупка справа», помощник с панелью условий подбора.
