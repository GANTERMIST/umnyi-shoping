# ShopNLU — своя модель помощника

Помощник «Умного Шопинга» не обращается к внешнему ИИ. Запрос разбирает **своя маленькая нейросеть ShopNLU**,
обученная под наш сервис, а ответ собирается из реальных данных поиска и каталога. Поэтому помощник не выдумывает цены,
работает без интернета до ИИ-сервисов, бесплатно и отвечает за доли секунды (дальше время уходит только на поиск в магазинах).

## Что делает модель

Из фразы покупателя она за один проход достаёт:

| Что | Значения | Пример: «ключ гта 5 для стима до 1.5к» |
|---|---|---|
| Намерение | купить · подобрать игру · отзывы · сравнить цены · вопрос о сервисе · приветствие · не про игры | купить |
| Игра / товар | кусок текста | «гта 5» → по словарю «Grand Theft Auto V» |
| Тип товара | ключ · гифт · аккаунт · пополнение · официальный магазин | ключ |
| Платформа | Steam · Xbox · PlayStation · Nintendo · Epic · GOG | Steam |
| Бюджет | число | 1500 |
| Жанр | кусок текста → жанр Steam | — |

Дальше `app/smart.py` по намерению: ищет предложения (с ослаблением условий, если ничего нет), подбирает игры из каталога
по жанру/бюджету/«похожие на», рассказывает отзывы Steam и Metacritic, сравнивает цену у продавцов с официальной,
отвечает на вопросы («чем ключ отличается от гифта», «что значит регион»), а на посторонние вежливо отказывает.
Уточнения в диалоге («а гифтом?», «а для xbox?») понимает: игру берёт из прошлой реплики. Профиль пользователя
(бюджет, платформа, типы) подставляется, если в вопросе этого нет.

## Как устроена

```
слово ──► хэши: само слово + буквенные кусочки по 3–5 + «форма» (цифры/латиница/кириллица)
      ──► среднее их эмбеддингов (48 чисел)           ← понимает опечатки, падежи и незнакомые названия
      ──► двунаправленная GRU (2 × 64)                ← учитывает контекст: «2077» в «cyberpunk 2077» — игра, в «до 2077» — цена
      ├─► метка каждого слова: O / игра / цена / жанр (схема BIO, декодер Витерби)
      └─► весь запрос (max + mean): намерение, тип товара, платформа
```

- 836 тыс. параметров, файл весов 1,6 МБ (`app/nlu/shopnlu.npz`).
- Обучение — PyTorch (`app/nlu/train.py`, ~2,5 мин на обычном процессоре), на сайте — чистый numpy (`app/nlu/model.py`);
  тест `test_numpy_matches_torch` проверяет, что numpy считает то же, что PyTorch.
- После модели — словарь народных названий (`app/nlu/lexicon.py`: «ведьмак 3», «бг3», «кс», «робуксы»…) и сверка
  с каталогом по буквенным триграммам (исправляет опечатки: «elden rign» → «ELDEN RING»).

## На чём обучена

Размеченных запросов покупателей игр в открытом доступе нет, поэтому датасет генерируется (`app/nlu/dataset.py`):
30 000 запросов из кусочков реальных формулировок (≈50 вариантов начала «где дешевле купить / почём / нужен…»,
20 форм бюджета «до 1.5к / полторы тыщи / 1 500 р», народные названия платформ «плойка / иксбокс / свитч»,
опечатки, перестановки, уточнения в диалоге, посторонние вопросы и не игровые товары «айфон 16», «ps5 slim»).
Названия игр — 190 популярных + каталог из базы; **15% названий отложены** и в обучении не встречаются.

## Качество

Актуальные цифры — `docs/МОДЕЛЬ_метрики.md` (пишется при каждом обучении). На 10.11.2026:

| Проверка | Намерение | Игра | Цена | Разбор целиком |
|---|---|---|---|---|
| Слепой тест — 35 запросов, написаны вручную и в подборе модели не участвовали | 94% | 94% | 100% | 91% |
| Ручной тест — 82 запроса (по его ошибкам дополняли генератор, поэтому оценка завышена) | 100% | 98% | 100% | 96% |
| 2000 сгенерированных запросов с незнакомыми играми | 100% | F1 96% | | |

Честно об ограничениях: модель иногда обрезает длинные незнакомые названия («Clair Obscur Expedition 33» → «expedition 33»),
путает «Dispatch стоит брать?» (покупка вместо отзывов) и принимает «реши пример 15…» за товар. Цифры на слепом тесте —
главная оценка; чтобы улучшить, добавляют формулировки в генератор и переобучают.

## Как переобучить

```
pip install -r requirements-train.txt
python -m app.nlu.train
```

Режим помощника задаётся `ASSISTANT_ENGINE` в `.env`: `model` (по умолчанию), `rules` (регулярные выражения),
`claude` (внешний API — только если явно включить и задать ключ). Разбор отдельно: `POST /api/nlu {"text": "..."}`.
